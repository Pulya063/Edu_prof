## 4. Locked visual direction

- Dark surface: `#171819` or the existing near-black token.
- Primary action/progress: lime `#B7FF2A`.
- Prediction, evidence and AI-adjacent state: violet `#D7C7FF`.
- Main canvas: cool light gray, with white content surfaces.
- Strong Manrope-led hierarchy and editorial composition.
- Restrained radii: approximately 9–10px controls, 16–20px major panels.
- Thin borders, subtle shadows and minimal glass effects.
- Data hierarchy over card quantity.
- No decorative motion that competes with the forecast.

The interface should communicate:

1. What education path is being considered?
2. What career target does it map to?
3. What is the investment?
4. Which outputs are available now?
5. Which outputs are blocked by missing evidence?
6. What is the next action?

## 7. Responsive contract

Validate these widths:

| Width | Expected structure |
|---:|---|
| 320px | One-column form, 16px-ish safe edge, no clipped labels or metrics. |
| 375px | One-column form, readable headings, touch targets at least 44px. |
| 768px | Top navigation, two-column form fields where they remain readable, stacked main panels. |
| 1024px | Compact side rail, stacked form and forecast panels without compression. |
| 1440px | Two-panel composition, balanced against the sidebar. |
| 1920px | Centered content; do not stretch panels across the entire window. |

Also check:

- 200% zoom.
- Portrait/landscape resize.
- Keyboard focus order and visible focus.
- `prefers-reduced-motion`.
- No horizontal page scrolling.
- Sticky forecast does not become a scroll trap.
- Long university, specialization and role names wrap safely.
- Error and partial-success messages do not move the primary action off-screen unexpectedly.

## 8. Motion contract

Use motion only for state communication:

- input focus and validation;
- forecast status changing from unverified to ready;
- live assumption-bar width updates;
- button hover/press/loading feedback;
- deliberate navigation active-state changes.

Rules:

- No `transition: all`.
- Normal UI feedback: about 120–220ms.
- Prefer opacity, color and transform; avoid layout-heavy animation.
- Reduced-motion mode must remove non-essential movement.
- Do not animate the entire page on every field edit.
